AdventureWorksDW2025 — ER Diagram

Four star schemas. Read each as: one dimension row → many fact rows, joined on the labeled key. PK = primary key, FK = foreign key.

1 · Internet Sales (online orders)

Grain: one row per order line · Measures: OrderQuantity, UnitPrice, SalesAmount, TaxAmt, Freight

4 · Product Inventory (stock)

Grain: one row per product per day · Measure: UnitCost, UnitsIn, UnitsOut, UnitsBalance · Powers slow-moving-inventory analysis

erDiagram DimProduct ||--o{ FactProductInventory : "ProductKey" DimDate ||--o{ FactProductInventory : "DateKey" FactProductInventory { int ProductKey PK int DateKey PK decimal UnitCost int UnitsIn int UnitsOut int UnitsBalance } DimProduct { int ProductKey PK string EnglishProductName decimal ListPrice } DimDate { int DateKey PK date FullDateAlternateKey }

Tip: the same dimension tables are reused across stars (conformed dimensions) — e.g. join FactInternetSales to DimDate three times with different aliases when you need order date, due date, and ship date in one query.
